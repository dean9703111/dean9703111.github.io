Bing Chat 圖像辨識的多種應用：產生食譜、以圖生圖、學攝影

林鼎淵
2023.08.10 更新於 2024.10.24 閱讀約 2 分鐘
本文目錄
  1. 辨識圖片產生食譜
  2. 以圖生圖
  3. 學攝影技巧
  4. 結論

Bing Chat 可以上傳圖片啦！讓筆者透過這篇文章向大家介紹 Bing Chat 在圖像辨識上的各種應用：「產生食譜、以圖生圖、學攝影」；一起體驗「長了眼睛」的 AI 有多麼強大！

小提醒：使用 Edge 瀏覽器，並登入微軟 Microsoft 帳號才能體驗完整的功能喔！

辨識圖片產生食譜

現在 Bing Chat 的右下角可以新增影像了。

你可以透過「貼上圖片或連結、上傳圖片」等方式提供影像。

這邊我貼上一道料理，詢問 AI 如何做出這道菜：「請問圖片中的料理如何製作？需要哪些食材？」

稍等一段時間後，他給了我非常詳盡的料理說明：

以圖生圖

我們知道 Bing Chat 可以透過 DALLE 產生圖片，這邊我們來實驗看看他能否將我們上傳的圖片以指定的風格呈現。

例如下面我上傳一張樹林的風景照，要求他：「幫我將這張照片改成平面設計風格」

產生的結果很符合期待，下面讓他嘗試改變圖片風格：「幫我為這張照片加上浪漫的風格」

一個簡單的樹林都能被改造成這樣，真的太驚人了！

學攝影技巧

你想知道一張照片是如何拍出來的嗎？只要提供照片，他就會盡力幫你想出拍攝的方法（就算這張照片不存在於現實）。

下面我就提供了一張由 Midjourney 產生的圖片，詢問（刁難）他：「請告訴我如何拍攝出這張照片」

感覺回答得有模有樣，那我再出困難一點的題目。

從 Bing Chat 的回答中，我們能感受到他非常努力幫我們達成目標，並把攝影的器材、步驟、技巧都說明的很清楚。

結論

除了上面的應用外，筆者也看到有人上傳圖片請 Bing Chat 來解題目、寫程式；但經過實測後結果相當慘烈（如下圖），這邊就不多做分享了。

讓我們一起掌握 AI 帶來的紅利 既然 AI 的發展勢不可擋，那我們要做的應該是去思考「如何利用他為自己帶來優勢」。 筆者相信，人不會被 AI 取代，只會被懶惰和守舊的想法取代，無論過去、現在、未來，跟不上時代的腳步就只能等著被淘汰。… dean-lin.medium.com
