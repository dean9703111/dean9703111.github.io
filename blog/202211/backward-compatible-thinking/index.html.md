# 程式可以向下相容，卻很難向上兼容？主管要下屬站在他的角度思考，卻忽略了這一點

- 作者：林鼎淵（Dean Lin）
- 網址：https://deanlin.net/blog/202211/backward-compatible-thinking/
- 發布：2022-11-09
- 主題：團隊合作
- 標籤：科技島專欄
- 摘要：市面上有很多的文章在講「向上管理、從主管的角度去思考」；不過今天筆者想從另一個角度切入，不知道大家有沒有想過：「為什麼程式通常可以向下相容，但卻很難向上兼容。」

市面上有很多的文章在講「向上管理、從主管的角度去思考」；不過今天筆者想從另一個角度切入，不知道大家有沒有想過：「為什麼程式通常可以向下相容，但卻很難向上兼容。」

> 舉個簡單的例子，如果你有在玩電腦遊戲，一定會先看簡介裡的「系統需求」，避免買了跑起來卡頓，甚至開不了的遊戲。
> 以 STEAM 遊戲舉例，在「作業系統」的部分，可能會建議電腦要有「Windows 7 64 位元 （不支援 32 位元）」以上的配備，如果你的電腦還是 Windows XP 32 位元，那基本上是無法運行的。

**當然人不會像程式一樣那麼死板，但也只能做出自己認知範圍內的決策。**

## 沒有相同權力，就很難擁有相同視野

因為筆者曾擔任過 Developer、Project Manager、Tech Lead 等角色，所以很清楚如果沒有真的站在那個位置，就很難理解對方為何會做出這樣的決策；畢竟不同角色面對的人、事、物差異極大，彼此的情報也有很大的落差。

當然市面上有非常多管理學、人際學、溝通學的書籍可以參考，業界也有很多優秀的講師分享、傳授自己的經驗；但說真的…無論讀多少本書、上多少堂課，都遠遠比不上自己實戰得到的經驗。

這不是在說學習沒有用，如果你有深厚的理論知識，在未來面臨突發狀況時，你的應對進退一定會比那些完全沒有準備的人更加完善（這裡我們排除那些天賦異稟的領導者）。

## 擴增自己的認知範圍

儘管職位不到，但我們還是有其他方法獲得實戰經驗。

就如同標題所述，大部分的主管都希望下屬站在他們的角度去思考，畢竟這樣他們交代任務會更為輕鬆。

> 向上兼容是跳出舒適圈的過程，需要勇氣與毅力。

在科技業，如果只站在工程師的角度，你可能會覺得沒必要幫主管想這麼多；但如果想在職涯上更進一步（ex：資深技術職、晉升管理職），懂主管在想什麼是非常重要的。

筆者建議要多與主管溝通，並適時表達自己的想法，在規劃任務時，可以看看自己與主管的想法是否一致；如果有分歧，可以與主管討論，了解他為何會做出這個決策（主管的決策也並非萬無一失，彼此的交流能讓規劃更為完整）。

這些交流是非常寶貴的，因為它讓你在取得權力前，能借用對方的視野去看問題，以此擴增自己的認知範圍；當然這一切的前提是，你有優秀的主管，並且他願意與你交流。

> **警告**：
> 這邊特別提醒大家，如果主管要你幫忙做出「不符職權的重要決策」，筆者建議要裝傻推掉；因為有些主管將做決策的任務交給下屬，不是為了重用他，而是在找人背黑鍋。

## 結語

如果一直做相同的事，在職場只會獲得年資，待在久也不會提升自己的認知範圍。

而本文提出的方法，儘管無法擁有與主管相同的權力，但我們能借用主管的視野，透過一次次反饋去優化我們的思維。
