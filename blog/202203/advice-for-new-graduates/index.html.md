## ㄧ、頂尖人士未必適合當你的導師

曾經有人說過，小學 3 年級最好的數學導師不是數學方面的專家，而是小學 4 年級的學長姐。

書局暢銷榜上充滿成功人士的傳記，如果你認真把它讀完相信會有不少收穫，但這些收穫難以轉換為你可以立即應用的知識，畢竟彼此無論是權利、財富、時空背景，還是看事情的格局都相差太大。

相較之下，如果你跟剛畢業幾年的學長姐約出去吃個飯、喝杯咖啡；你從中得到的收穫往往可以立刻實踐，這是因為：

- **年代接近**：學長姐的經驗也適用於你
- **較無利害關係**：通常可以收到較為真實的反饋
- **年紀相仿**：你比較能夠認同對方的想法

**備註**：如果你在職場上有幸遇到願意與你分享經驗的前輩，那是極其幸運的，請好好珍惜與把握。

## 二、投資有風險，但投資自己絕對不虧

筆者身旁大部分的朋友是工程師，他們在專業領域是佼佼者，但在投資方面卻很常失去理性，比如：

- **想透過高槓桿、高風險投資一夕致富**：期貨、權證、融資、虛擬貨幣…這些東西不是不能碰，但筆者看過太多自認為高手的人被當韭菜割；如果你還是想入場，請先做好財富打折的心理準備。
- **交往時只有自己在付出**：感情需要雙方經營，如果只有某一方在付出；那這種畸形的平衡遲早會業力引爆。
- **購買非必需奢侈品**：奢侈品能給人帶來短暫的快樂，但通常他們的貶值也非常快速；如果要購買，請先思考自己如果突然失業半年、臥病在床一年，是否會需要這筆救命錢。

在自我成長方面的投資，筆者認為有兩大類型是 CP 值最高的：

- **財商**：培養正確的投資觀念，了解資產分配是非常重要的，越早擁有這些知識越好。
- **情商**：社會上有形形色色的人，與其用自己有限的人生閱歷去碰撞，不如先了解遇到什麼樣的人要如何應對進退。

在學習方面的投資，不同情境有各自合適的方案：

- **買書、線上課程**：不同於網路上分散的知識，透過書籍與線上課程你能夠有系統地學習知識。
- **補習班、家教**：如果你是初學者，又想學習新的技術，補習班、家教會更為合適，在初學的陣痛期如果沒有人可以詢問很容易會自我放棄。
- **購買專業諮詢**：儘管價格相對昂貴，但對於茫然、沒有方向、遇到瓶頸、想要改變的人而言，筆者認為是幫助最大的。

## 三、不管收益在高，也不要跟品德有問題的人合作

筆者曾自以爲很聰明，認為過往那些被坑的人都是經驗不足。

但理想很豐滿，現實很骨感，慘痛的事實證明，如果你合作的對象品德有問題；除非你的品德比他更差，不然你肯定是倒霉的那一方。

人生很短，筆者在這裡就不分享與惡勢力鬥爭的經驗了；與其浪費時間鬥爭，還不如**一開始就不要讓自己陷入這個被動的窘境**。

## 四、維護主管的利益，就是維護自己的利益

皮之不存，毛將焉附

如果還沒有離職的打算，**建議在遇到部門問題或是主管遭到無理挑釁時，你不要站在旁邊看戲，而要堅決地跟他站在同一陣線**。

主管要倒不容易，但他想弄你很容易。

人都有情緒，同事間私底下難免會評論主管，有些情緒化的人甚至會建立群組來罵主管；如果你想參與其中，就要先思考這些對話被錄音、截圖的可能性，如果主管收到這些資訊，你與他先前建立的信任感將會全部瓦解。

管理者是需要形象的，或者說：「是需要塑造形象的！」如果一個管理者的形象不好，他所部署的命令就沒有人會貫徹執行，隨之而來的就是部門績效不彰，接著部門就可能遭到公司整頓、裁員；通常在上述的歷程中是很難積累好的履歷，因此建議：「就算是為了自己，也要維護主管的利益。」

**備註 1**：電視劇、電影裡面有很多幹掉主管上位的劇情，但這在現實生活中要達成的可能性極低，不要總以為自己是主角，其他人都是 NPC。

**備註 2**：主管也是會被幹掉，通常是陣亡於派系鬥爭，或是跟更高層的意見相左而被離職。

## 五、不要排斥新技術，要第一時間了解它

如果你跟筆者一樣是工程師，那學無止盡就是我們的宿命。

如果你剛出社會，你更要無所畏懼的接觸新技術，**因為剛推出的技術往往還沒有專家誕生**，此時的你跟那些老手站在相同的起跑線上，而且許多公司不管是為了企業形象還是真的想要跟上時代潮流，他們都不惜開出高薪網羅人才，**在新技術的紅利期往往會開出高於相同職位 50%-150% 的薪水**。

- 像是前幾年 React Native、Flutter 這類可以開發多平台的框架就很受企業歡迎，因為只需要維護一套程式碼就能在多個平台發布，所以就算開出的薪水較高也符合企業成本。
- 而如果你是維運工程師，熟悉 GCP、AWS 以及 K8s 佈署也能獲得許多企業的親睞，因為過去實體 Server 在建置、部署、維護方面的成本很高，如果將這些操作轉移到雲端上面就能夠更合理的依據實際使用量存取資源。
- 隨著網路世代的發展，大流量、大數據的場景越來越普遍，新型的 no SQL DB（EX：MongoDB、Redis）也逐漸從新技術變成業界必備的技能。
- 而最近這陣子被炒得火熱的 Block Chain、NFT、Web 3.0…，如果你對他們的技術有一定程度的理解就能輕易取得高薪。

**備註**：就算成為了主管，也不能放棄技術；這個階段不需要精通新技術，但絕對要了解新技術，否則是很難在新進工程師面前建立威信。
