## 1. 離職原因

不管對前公司抱有多少不滿，請不要在面試時由你口中表達出來。

就算遇到面試官在批評你的前公司：「聽說你前公司高層的管理作風很有問題，朝令夕改，決策錯誤也不願意承認。」

筆者也強烈建議你不要附和，婉轉的帶過就好：「每個人都有自己的管理風格，我也是從前公司學到很多東西。」

### 1.1 為什麼想換工作？

重點：要說出具體的原因，跟面試的公司有關聯性更好

- **單打獨鬥轉為團隊合作**
我現在這份工作是專案外包公司，大部分的專案都是單打獨鬥，這讓我累積了非常多的實戰經驗；但也讓我意識到儘管自己可以完成每項任務，但我對後端開發這塊更有心得，我希望可以在自己擅長的領域做的更加出色，並期待與優秀的團隊一同打造出受到市場認可的產品。
- **完成階段性任務，想突破舒適圈**
在 3 個月前，我已經完成公司期待的產品；現在產品的結構趨於穩定，只剩下一些細節需要擴充與維護。
我希望趁自己年輕的時候多嘗試不同的領域，來這裡面試前我有先做功課，了解貴公司是一個年輕有衝勁的團隊，是我所嚮往的工作環境。

> 筆者會用「生涯規劃」做開頭，然後再把話題轉移到面試公司身上。

### 1.2 什麼情況下會想離職？

忌諱：盡量避免批評前公司

請用委婉的方式說出真實理由，也許會失去一個 Offer；但至少避開了自己的雷區。

- **辦公室政治**
我希望公司的成員都是團結一心，努力想把產品做好；我無法接受好的產品因為派系鬥爭而被犧牲。
- **常態加班**
如果有緊急狀況我可以配合公司加班，但我無法接受常態加班；我希望自己可以在工作與生活間取得平衡。
- **加班沒有加班費**
員工加班是為了幫公司解決問題，如果公司沒有支付這塊的酬勞；除了違反勞基法外，辦公室的氣氛也會非常低迷，我無法在這樣的環境下工作。

因為說真話失去的工作機會不需要太留戀，假設你就是因為無法接受每天加班 3 小時才離職；你在面試時又不提出自己無法接受常態加班，搞不好這間公司每天要加班 6 小時。你不說出自己無法接受的點，進去後崩潰能怪誰？

> **備註**：勞方與資方的思維模式差異極大，如果你今天直接說是因為薪水凍漲、加班沒錢、升遷遇阻而想離職；面試官就會認為是你能力不足、團隊溝通有問題、沒做好向上管理；會將原因歸咎在求職者而非公司，所以請模仿上面的方式換句話說。

## 2. 工作環境

### 2.1 聊聊自己期待的工作地點、內容、氛圍，並做個排序

- **工作地點**
我希望工作地點的通勤時間不超過 30 分鐘，因為通勤時間太長會壓縮到睡眠時間；進而導致上班的精神狀況不佳。
- **工作內容**
在工作內容方面，我期待有挑戰性的專案，即使是沒接觸過的領域我也很樂意學習。
- **工作氛圍**
在工作氛圍方面，我希望同事間可以互相幫助，在開發遇到難題時能夠討論並解決。

筆者個人排序：「工作地點 > 內容 > 氛圍」

### 2.2 你了解我們公司的產品嗎？

`重點：一定要事先了解/試用過面試公司的產品`

- **用稱讚作為開頭**
我覺得貴公司不僅是有願景的公司，更是一群具有實力實現願景的團隊。
- **簡單敘述產品**
在來面試前，我透過一些報導了解貴公司近幾年在大力推動「數位轉型」。
而貴團隊目前開發的這款 App 我也有下載；在使用的過程中我感受到開發人員對使用者的用心：

- 功能貼合使用者的日常生活需求。
- 打破傳統思維，可以更靈活的使用點數。
- 結合地圖讓抵達新生活圈的人，可以快速知道周圍有提供哪些好康活動。

> **備註**：有些公司除了要你敘述他們的業務之外，甚至會請你提出哪裡可以改善；這個問題可以事先搜尋網路的評論，但請用優化而非批評的角度來敘述。

### 2.3 你覺得自己適合這個產業嗎？

重點：要對產業有基礎的認知，說出自己與產業相符的特質

我認為這個產業有以下特點

- **技術快速輪動**
我本身是一個勇於嘗試新技術的人，我相信唯有不斷增強自己的技術才能走在時代的前段班。
- **產品服務第一線客戶**
不怕客戶提需求，只怕沒有客戶；我對待產品的態度就像是自己的孩子，我希望它可以越來越好。
- **未來發展潛力大**
這個產業目前還是藍海市場，公司也在快速發展的階段；而我對環境變動的適應力很強，相信自己能跟著團隊一起成長。

### 2.4 你期待加入什麼樣的團隊？

我希望加入一個願意溝通的團隊；主管在這個團隊中有自己的主見，但也願意聽取成員的建議；而同事都有自己專精的領域且願意互相交流成長；在面對困難時，大家會齊心協力設法解決。

### 2.5 你有無法合作的人嗎？

忌諱：避免用前公司的人來做舉例

- **拒絕溝通的人**
如果合作對象拒絕溝通，那專案很容易因為這個人而卡在某個功能無法 Release，嚴重影響開發進度。
- **情緒管理有問題的人**
如果合作對象完全看當天的情緒來決定如何做事，那產出的品質與效率將完全無法預估；總不能把事情交給一個未爆彈做吧？

## 3. 薪資

### 3.1 你的期待薪資是？

重點：請說出一個明確的數字或是區間，不要再說出：「依公司規定了。」

如果你說的是一個區間，那區間的最低值要在自己能接受的範圍之上，因為公司通常都是採數字區間裡最低值來核薪。

面試官或是人事會依照你說出的數字決定後續走向：

- **符合行情**
如果學經歷都符合需求，通常就不會繼續往下問了。

- **略高於行情**
你要能說出自己跟其他工程師的差異，公司才可能願意用高於行情的價格僱傭你。

> 通常會往「3.2 為什麼你覺得自己值得這份薪水？」發展。

- **符合行情，但想要壓你薪水**
有不少公司會詢問求職者上一份工作的薪水，甚至在核薪階段要求提供薪資證明文件；這部分就由讀者自行斟酌，因為提供與否各有利弊。
這邊來說一下弊的部分，如果你在沒良心公司待太久，就算功績卓越，薪水也無法跟上市場價格；因此部分面試官會用這個理由來壓你薪水。

> 通常會往「3.3 你的期待薪資與現在的薪水相比漲幅有點太大」發展。

> **備註**：筆者在接受面試前會先了解這個職位的預算範圍，故此階段會直球對決；若讀者尚未確認公司預算，請先試探公司的底線。

### 3.2 為什麼你覺得自己值得這份薪水？

重點：說出自己與其他工程師的差異

- **硬實力**

- 我擁有的技術與職缺相符，可以快速上手成為即戰力。

- **軟實力**

- 過去跨團隊溝通、資源協調的經驗讓我知道如何保護團隊並且爭取資源。

- **其他**

- 寫文章、寫書的經驗讓我擁有極佳的資訊統整能力。
- 下班後的學習除了開拓自己的視野外，我還會將新的知識與技術帶到公司，讓大家一起成長。

### 3.3 你的期待薪資與現在的薪水相比漲幅有點太大

重點：用能力談薪水，而不是用年資

我相信透過這幾次面試，貴公司對我的能力與經歷是有所了解的；我認為自己開出的期待薪資是符合市場價格的，也相信貴公司在核薪上，是依照人才的能力，而不是用過去的薪資來做衡量。

> **備註**：此問題在期待薪資漲幅超過 20% 時較容易出現。

## 4. 自我成長

### 4.1 平常會怎麼精進自己的能力？

重點：列出具體事項，最好有陳列在履歷上

- **技術文章**
在下班後我會持續精進自己的技術，並透過撰寫技術文章將知識內化；為了要給讀者呈現最正確的知識，我也需要看大量的資料做為輔助，這個過程讓我學習到更完整的知識。
- **Side Project**
常常有朋友跟我分享他們的靈感或是工作遇到的困難，如果剛好這些問題是能夠用技術解決的，我就會動手把它實踐出來，像是我之前曾用爬蟲技術解決小編朋友搜集資料的需求。

### 4.2 會不會覺得自己學得太雜了？

重點：證明這些學習對工作帶來的幫助

我學習的技術會分成兩種，一種要到達專業的深度，另一種則是拓展我的眼界。

像是我具備伺服器端的知識，在開發前端、後端的時候就會比其他工程師注意更多細節，對資源的管控也有更深刻的體悟。

撰寫技術文章在訓練我溝通表達與教學的能力，你要對技術有深刻的理解，才有可能用自己的語言讓其他人理解。

而寫 App 讓我從不同的角度去思考後端 API 的設計，更深刻的體會到回傳的格式、HTTP Status Code 對開發者的重要性，這些經驗讓我之後跟 App 工程師合作時更加順利。

> 我相信沒有白走的路，過去的經歷都會成為未來的養分。

## 5. 未來規劃

> 「人生就像射箭，夢想就像箭靶，如果沒有箭靶，你每天拉弓有什麼意義？」── 銀河補習班

### 5.1 你在未來 3~5 年有什麼樣的職涯規劃

重點：說出自己的具體規劃

如果有榮幸加入貴公司

- **短期**
我會先熟悉工作所需技能、了解專案；並學習產業知識，讓自己的能力能夠完全符合職位所需。
- **中期**
期待自己能擔任跨部門溝通的角色，為團隊帶來更大利益，並朝管理職的方向發展。
- **長期**
希望自己可以擔任團隊的 Leader，帶領團隊為公司創造更多價值。

> **備註**：依照自己的職涯規劃敘述就好，並不是每個人都想往管理職發展，公司需要多元的人才。

### 5.2 你進入公司後會想學到什麼？

重點：想學的東西最好要跟產業以及你現在的技術有關聯性

> 以電商產業舉例

電商這個產業的 Know-how 對我來說新的領域，儘管我有自學一些高併發高流量以及 NoSQL 的知識；但面對真實的 Big Data 數據處理、NoSQL 與 Relation Database 結合的應用，都還是需要再學習並與前輩請教的。

## 6. 其他

### 6.1 有沒有應徵其他公司？

筆者建議照實回答：「`有`。」有些公司問這個問題是因為他對你感興趣，想了解有沒有潛在競爭者。

> 應該很少人準備換工作，卻只應徵一間吧？

如果公司對你非常感興趣，他們甚至會詢問你是否有拿到其他公司的 Offer、具體的待遇是多少、你什麼時候要做決定。

如果遇到上面的情境，恭喜你獲得薪水談判的權利；但這並不代表你可以獅子大開口，只是談判空間更大而已。

### 6.2 說說看自己的優點

重點：說出的優點必須要有實際案例作證

當面試官問到這個問題時，很多人都會反射性的用形容詞來回應，比如：「積極進取、樂於助人、懂得應對進退…」如果你只用形容詞回答，面試官是不會接受的，在沒有實際例子包裝前，一切的形容都毫無意義。

筆者會建議改成這樣表達：

- **積極進取**
下班後繼續充實自我，目前已經在 Medium 平台上發表了 60 餘篇技術文章；並且在 GitHub 上面分享自己的 Side Project。
- **樂於助人**
我會為團隊的新進成員準備 OnBoard 文件，帶他們了解工作所需的技術與知識，使新人快速融入這個環境成為有效戰力。
- **懂得應對進退**
我會注意職場上的禮節，像是主持會議時會穿著得體的服裝、與長官交流時不會因為私下交情而沒大沒小、如果請假出去玩會帶當地的特產與同事分享。

### 6.3 談談自己的缺點

忌諱：說自己沒有缺點，或是說出來的缺點不是缺點

很多求職者會回答一些根本是優點的缺點，比如：「做事太過積極造成同事壓力、擇善固執不懂得妥協…」聽到這類回答時，面試官會覺得有說跟沒說一樣，就像是從參考書裡面抄來的，毫無靈魂。

筆者建議關於缺點的回答可以從缺乏的技能出發，說出缺點的同時也要提出你打算如何改善它；盡量避免說性格上的缺點，因為面試官無法確定你的性格是否會改善，但技能是可以培養的。

筆者建議的回答結構：

- **缺乏的技能**
我在一開始兼任專案經理的時候缺乏時間管理的概念、也無法分辨任務的輕重緩急；導致上班時間幾乎都在開會、整理需求，下班後才有時間著手規劃與執行任務。
- **如何改善**
但我覺得用加班解決問題不是一個好方法，所以我開始閱讀時間管理的書籍，像是理查．柯克的 80/20 法則。
這本書讓我知道如何過濾掉不必要的會議、需求，學會分清楚每個時間點該做的事情。
- **接受建議**
在專案管理方面我還有很多需要學習的，我也非常樂意接受您的指導，希望在未來我可以透過這些技能，幫助公司提高更多的生產力。

### 後記

> 讓你變強的不是面試，而是面試後的每一次整理；若缺少這個步驟，你下次還是會犯同樣的錯誤。

你未必認同我的回答方式，我的回答也不可能適合每一位讀者；請依據自己的人生閱歷給出最合適的回答。
