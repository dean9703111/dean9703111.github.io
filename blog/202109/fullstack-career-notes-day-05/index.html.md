## 1. 了解自己與市場的差距

有些人認為「面試」是對公司不忠誠的一種表現；但我認為面試是一種「提醒」自己與市場差距的行為。

### 1.1 了解市場上所需要具備的技能

每個產業都有自己的 Know-how，如果你在同一個產業待太久，你的思維與技能也會被限縮在這個產業之中，舉例如下：

- **接案公司**
在熟悉一個完成案子的 SOP 後，往往後面的案子也會依照這個 SOP 進行；而且接案通常都有時程壓力，所以`不求有功，但求無過`的心理會讓人避免加入不熟悉的技術，時間一拉長，你的技術可能就與社會脫節了。
- **傳統產業**
大部分會接觸到的是該產業的管理系統，主要使用者都來自企業內部，通常這類系統比較沒有開發時間的壓力，但因為系統先天就是為了企業服務，所以`較少接觸到大流量`的情境。
- **新創公司**
依照你進去的時間點會面臨不同的問題，但通常要面臨前期快速開發累積的技術債，且因為是新創，許多`流程與體制`都相對不完善。

除非你打算在某個產業一路走到老，不然我建議你`透過面試去了解不同產業所需要的技能`；時刻保持憂患意識，我們並不知道自己還能待在舒適圈多久，也無法確定現在賴以為生的技能在幾年後是否會被產業淘汰。

### 1.2 確認自己的行情

我相信絕大多數人都不滿意現在的薪水，認為自己值得更高的行情；如果你有這樣的想法為何不直接去面試？

每間公司的調薪制度不同，如果你在規定一年調薪不得超過 5% 的公司上班；即便你立下汗馬功勞、一個人扛下整個部門的任務，幾年下來，你的薪水也會落後市場很多；而透過面試，你可以很清楚地知道這些年來，自己累積的是`年資還是實力`

### 1.3 思考現在的公司是否適合自己

在同一個框架下待太久，你會誤以為外面的世界都長一樣。

「繼續待在原本的公司，還是要出去闖蕩？」這個問題隨著年齡的成長，你會更傾向於前者的選擇；因為比起獲得，人類更害怕失去。

`但生命只有一次，你的選擇也不是只有一個`；為什麼不透過面試來探索不同的產業呢？在這個過程中你可以思考自己感興趣的產業、適合的公司文化；面試，是一個低成本的嘗試，讓你看看外面的世界如何運行。

## 2. 你可以從面試中獲得的好處

儘管準備面試很累，請特休寫「私事代辦」還要被追問；但我相信每場面試都有你能學到的東西。

### 2.1 看到自己的盲點

真正的勇士敢於直面慘淡的人生，敢於正視淋漓的鮮血。── 魯迅

比起順風順水的面試，我更期待自己`被問到啞口無言的面試`；因為後者你往往能看到自己更多的盲點。

在習慣現在的工作之後，我們通常會選擇自己最有把握的方式來解決問題；久而久之，我們成長的只有年資，所擁有的只有這間公司所需要的技能、以及公司裡面的人脈；如果沒有足夠的外力刺激，這種`溫水煮青蛙的模式是會把自己給弄廢的`。

通常我們周圍的朋友也是同溫層居多，他們並不具備指出你身上盲點的能力；而面試卻是一個非常棒的機會，因為對方不認識你所以沒有預設立場，為了確保你是合適的人選，他們`問的問題可不會那麼客氣`，這樣的做法反而可以非常直接的`讓你知道自己所沒注意到的盲點`

### 2.2 提升自己的表達能力

如果沒有事先思考過，就算是自己熟悉的議題，也常常會不知從何說起。

在面試的過程，你要不斷展示自己的價值，並且要能`讓初次見面的人輕鬆吸收你想傳達的東西`，你可以先嘗試下面幾道簡單的題目，看看自己能否流暢回應：

- 你可以說明一下最近一個專案的技術架構嗎？
- 在資料庫設計上，你會注重哪些細節？
- 你過去在哪個專案有遇到挫折，你是如何面對與解決的？

上面的題目都算是面試常見的問題，但如果要你用口語表達其實很容易卡住；`並不是回答不出來，而是大腦想要表達的資訊量太多`，而導致表達的內容斷斷續續缺乏邏輯體系。

在後續的文章中會舉出一些面試問題作為範例，讀者可以參考筆者回答問題的思路；我相信這些問題只要你本身硬實力夠，有空的時候`刻意練習`，通常在經歷幾場面試後就能掌握回答的方式並瞭解對方想得到的資訊。

### 2.3 增加自己的談判籌碼

有些公司在明知你有卓越貢獻的狀態下也不願意替你加薪，甚至你拿著成績單去找上級也會被以公司制度為由只能微幅調整，如果你對這間公司還有留戀；我的建議`絕對不是什麼加強向上管理能力，或繼續努力總有一天會被發現的幹話`，因為這些做法是否有效完全取決於上級的良心。

與其長期投資一個不確定的未來，又將最後結果的決定權交到對方手上，還不如自己主動獲得談判權；`假使你能夠拿到不錯的 Offer，它是可以做為跟公司談判的籌碼`，因為你已經證明自己是有能力取得更好的 Offer，也保留了談判破局的後路。

實際在談判時，筆者建議你用比較委婉的方式跟上級溝通，比如：「`我不是很在意錢，只是最近剛好遇到了XXX的機會，他開了YYY的薪水讓我了解到自己的市場價值；但比起那些，我更想要留在這間公司跟大家繼續打拼，想了解有沒有調整的空間。`」

`警告：這個是殺手鐧，一間公司大概用一次就是極限了，即使是暗示也沒有人喜歡被威脅；部分公司會因為這些話會給你貼上「不忠」的標籤，你絕對要經過謹慎分析與思慮後再使用這招。`

## 3. 面試有哪些管道？各自的優劣？

前面說了那麼多面試好處，現在讓我們來了解不同面試管道的優劣吧～

### 3.1 自己投

- **優勢**

- **目標明確**
你一定會先找自己感興趣、或是符合能力的公司投遞履歷；所以較不會出現你對這間公司一無所知就去面試的狀況。

- **缺點**

- **已讀不回**
你感興趣的職缺，通常很多人都感興趣，這造成履歷經常石沈大海。
- **需要更多的時間準備**
通常要依據對方公司的需求客製化自己的履歷，以其增加得到面試的機率。
- **不確定因素較多**
除非是大公司或是網路聲量高的公司，不然相關的薪資待遇、公司文化都無法事先得知。

### 3.2 公司主動找

- **優勢**

- **擁有話語權**
如果能力符合對方需求，你在談薪資待遇上會擁有更多的優勢。
- **提前知道該職缺基本信息**
在收到人資的電話後，你可以先在電話中詢問該職缺的基本資訊，以此快速判斷這個職缺是否適合自己。

- **缺點**

- **不理解內部情況**
合格的人資不可能批評自己的公司，就算真的有問題也會將其美化，所以你其實無法從人資那裡得到太多有效資訊。

### 3.3 朋友推薦

- **優勢**

- **了解內部狀況**
進去後裡面有朋友照應，可以快速熟悉環境。
- **錄取率超高**
只要你技術不要太差，面試就只是走個過場而已。

- **缺點**

- **友情未必能保全**
能當朋友未必適合當同事；如果工作上合作不愉快，往往連朋友都當不成了。
- **地位差距造成的心理負擔**
在當朋友時你們是平輩，但如果進入公司後你變成朋友的下屬，你還能夠保持平穩的心態嗎？

**友情提醒**：筆者身旁有朋友`把以前的長官找來當自己的下屬，然後幾乎管不動`，奉勸各位工作就已經很辛苦了，不要再做自找麻煩的事情。

### 3.4 獵頭推薦

- **優勢**

- **情報完全**
獵頭手上的公司非常多，所以他們對公司內部的文化氛圍、工作模式較不會避而不談；優秀的獵頭對公司的了解程度甚至高於公司的人資，你想問的問題，只要在合理範圍內他們都很樂意為你解答，比如：

- 完整面試流程、考古題
- 公司真實環境（因為有些他們過去推薦的人已經進去任職）
- 公司的核薪邏輯

- **錄取機率高**
他們會找你，通常是因為你符合他們手上 JD 的條件；這種媒合方式省去了你大海撈針的時間。

- **缺點**

- **你需要在短時間證明自己**
當你錄取後，公司需要支付一筆錢給獵頭，有些公司與獵頭的合約上載明：「`如果錄取人員的工作能力在 3 個月內未達要求，獵頭必須尋找替補人員`」；也就是說你必須是真正的即戰力，不然可能做不到 2 個月就被 Fire。
