準備履歷，是在培養自知之明。

整理履歷是持續性任務，但許多人都把它當成一次性任務；讓我們回想一下，入職後有多久沒有整理履歷了。

1. 了解履歷的重要性

1.1 履歷的用途

大部分的人整理履歷都是為了面試用，少部分的人整理履歷是為了給自己警惕；但很少人意識到，你整理的履歷是可以給現在的雇主看的。

員工會跳槽除了想轉換工作環境外，我相信「錢」是非常重要的一個因素；許多企業的內部規範就是一年加薪最多不得超過 5%，這代表你留在原本的公司兢兢業業甚至趕不上台灣的通貨膨脹；不過凡事皆有例外，如果你有傑出的具體績效，還有敢於直接向上級反映的勇氣，衝撞體制打破規則也是很有可能的！

具體做法請參考 [Day 30]掌握薪水談判的秘訣，取得自己應有的報酬。

公司的人很多，如果沒有主動說出來，上級根本不知道你有這些貢獻；而「具體績效」這個東西如果沒有定期整理，我相信絕大多數的員工都拿不出來，只能用一些很模糊的語言帶過。

筆者認為，與其加班做樣子給長官看，還不如把這些時間用來整理履歷，提升加薪的可能性。

1.2 履歷的種類

筆者將履歷分成兩種：

  • 求職用的履歷
    就是放在人力銀行上的履歷，內容較為精簡；除了常見的 104、1111 求職網以外，這裡筆者推薦使用CakeResume這個網站，在上面有非常多履歷的範本，且提供良好的介面讓你製作履歷；把履歷放在上面後會時常有獵頭、公司的人資與你聯繫。
  • 鉅細彌遺的履歷
    這是你要經常維護與回顧的履歷，在這份履歷中要盡可能把所有跟工作有關、能為自己職場加分、彰顯個人風格的事蹟放上去；不怕內容多，就只怕你沒東西可以放。
    人的記憶力有限，你或許能記得這個月所用到的技術與功能，但如果突然有人問你兩年前的某個 Feature 是用什麼 Design Pattern 設計的；除非你本身記憶力超群，否則在沒有筆記的狀態下是幾乎不可能回答出來的，這份履歷就是為了幫助你快速回憶當時所做過的事情。

1.3 為什麼要養成整理履歷的習慣

寫履歷的時候常常有一個感覺，我明明在這份工作做了很多的事情，但一時之間就是什麼也想不起來。

絕大多數人在即將面試時才開始準備履歷會用到的素材，此時會遇到以下常見的問題：

  • 你想在短短幾個小時就把過去好幾年的履歷彙整起來；導致準備履歷的過程極為厭世，甚至很多人因為覺得太麻煩而放棄整理。
  • 許多素材是有時效性的，時間過了你就很難取得，像是：
    • 你上台演講、報告、分享的照片
    • 你負責的產品上排行榜的截圖
    • 團體比賽的合照
  • 整理完履歷後，赫然發現自己居然沒有什麼拿得出手的經歷。

1.4 了解定時整理履歷的好處

這裡的「定時」，我個人的建議是每個月都至少要審視及更新一次自己的履歷：

  • 一個月整理一次，這樣更新的內容有一定的份量又不至於太多。
  • 因為每個月都有整理，你可以很明確地知道自己是否有持續成長。
  • 如果發現自己這個月，幾乎沒有任何值得紀錄到履歷的資訊就要有所警惕。
  • 比起有計劃的轉職，更多人的轉職是受到情緒左右的；不過你如果有定時整理履歷，你就享有隨時做自己的權利。

2. 求職履歷該有的基礎元素

在認知到履歷的重要性後，這邊筆者先把一個履歷該有的基礎架構列出來給大家看：

  • 個人基礎資訊
    • 姓名
    • 個人照片
    • 職稱
    • 聯絡方式
  • 自我介紹
  • 技能
    • 專業技術
    • 職場溝通工具
    • 證照
    • 其他
  • 學經歷
    • 公司
      • 任職機構
      • 部門與職稱
      • 任職起訖時間
      • 工作內容與專長
    • 學校
      • 科系、學歷
      • 實習經驗
      • 專題
  • 其他
    • Side Project
    • 自媒體
    • 特殊經歷

上面只是基礎的骨架，方便讀者快速檢視自己的履歷是否有遺漏的資訊。

很多人都說履歷需要控制在一頁，這樣面試官才能聚焦；但我不完全認同「一頁」這個說法，因為有些履歷比較豐富的人，用「一頁」呈現的畫面太過壅擠，所以我會把重點放在這份履歷能否讓對方對你感興趣上。

3. 撰寫履歷重要的細節

3.1 自我介紹

你希望給面試官看到的「人物設定」

這裡有兩種選擇：

  • 成長故事
    • 字數不要超過 200 字
    • 重點描繪給自己重大成長的經歷
  • 能力條列式
    • 建議選最能代表自己的 5 個能力
    • 這些特質都要有相關的實例佐證

筆者較推薦用條列式來做自我介紹，因為成長故事除非你的文筆極佳，否則真的很難讓人快速認識你；條列式的範例如下：

  • 豐富的實務經驗：任職期間完成 7 個百萬級別、1 個千萬級別專案；擅長分析系統操作流程、資料庫規劃；熟悉 GIS、IPC 產業知識。
  • 具備優秀的溝通能力：能有效統整客戶提出的需求，在了解對方面臨的痛點後，經過協商給予合適的解決方案。
  • 對系統品質的要求：遵循 Git flow 進行開發，並在 CI/CD 的 Stage 中加入 Unit Test 確保功能穩定性。
  • 善用專案管理工具：在工作時使用 Jira、Confluence 與團隊溝通，藉此追蹤工作進度並維持專案品質。
  • 自主學習：在空閒時研究能幫助或娛樂朋友的 Side Project，並保持撰寫技術文章與吸收新知的習慣。

筆者透過上面的條列式，營造出自己是一個：「有技術能力、溝通能力，會利用工具輔助工作且樂於分享的人。」

備註：除了介紹自己外；你可以放一些周圍朋友、長官、客戶對你的評價，第三者的評價對面試官來說是更加可靠的訊息。

警告 1：假使你在履歷中列出很多參加活動的事蹟，面試官會先在心裡認為你應該是一個很外向的人；但如果面試當天你表現得畏畏縮縮，那就是人物設定崩壞，就算你專業技能過關，面試官還是會對你履歷上寫的內容抱持懷疑的態度。

警告 2：我只是提供範例，讀者一定要依據自己的情況做調整；不然面試官一問你就ＧＧ了。

3.2 照片很重要

很多公司會把沒有照片的履歷過濾掉，所以你不但要放，還要謹慎挑選，讓你的人物設定更加立體。

  • 履歷上的大頭貼
    因為很多人都是用手機自拍，或是放生活照；因此如果你放的是照相館拍的專業形象照，你在眾多履歷中就會非常顯眼，花錢增加記憶點，我認為非常值得。

    如果你剛好在台北可以考慮在師大商圈的照面 Hi PHOTO，筆者就是在這裡拍的，當時含妝髮 1200（非業配 XD）。

  • 得獎照片

    • 個人獎：你要跟獎狀（獎牌/獎盃）一起入鏡

    • 團體獎：你要站在 C 位拍照

      特別建議：如果是團體獎，最好讓每個成員都有一張自己在 C 位的合照；不然放一張自己在邊緣的照片真的很尷尬。

  • 演講照片
    公司教育訓練、回母校演講、產品 Demo…取得上台分享的機會時，記得多拍幾張照片，如果可能，當簡報畫面停留在講師介紹畫面時，從觀眾席最後一排拍的視覺效果最佳。

雖然這篇文章講的有點誇張，但打理自己，把自己最好的一面展現出來是很有必要的。

3.3 只放自己最熟練的技術

從資工相關科系畢業的人都學過不只一種程式語言，如果是初入職場，你可以把這些技術都放到履歷上以期獲得更多面試機會。

但如果今天你已經畢業了好幾年，公司所使用的技術跟你學校的完全不一樣；那我請你把那些快遺忘的技術從履歷中移除。

在履歷上寫自己會很多技術不一定會加分，在有一定年資後，有些公司看到履歷上會一堆技術的人反而會產生：「樣樣通、樣樣鬆」的想法；但如果你對自己的技術都很有信心，那就全放吧！很多公司還是希望招攬技術全面的人才，因為這類的人才只要人格特質合適，稍加培養就可以往技術管理職的方向發展。

3.4 挑最能展示自己的專案放

你可能在一間公司接手過 10 幾個專案，但不要真的把 10 幾個專案一股腦的全部放到履歷上啊！

你只要放自己貢獻度最高、技術最具代表性的 2~4 個就很夠了；不然放一些你只是協助撰寫幾隻 API、幫幾個頁面切版的專案意義不大，當面試官問到這些專案的技術與規劃細節時，你也容易卡詞說不出個所以然。

履歷只是大綱，無論你有多少豐功偉業，我相信一定會有先後順序；面試官每天需要面對很多求職者，他如果無法從履歷中有效得到你的訊息，那就是無效履歷；你所列出的大綱就是讓他挑選有興趣的地方問，如果你鉅細靡遺的呈現，他真的很難挑重點。

4. 擴充自己的履歷

每個人都是從菜鳥成長起來的，下面我推薦幾個無論你是菜鳥還是老鳥，都非常值得長期投資的項目。

4.1 Side Project

上班很累了，下班如果還是做技術雷同的專案我覺得太折磨人了，而且也無法從中獲得太多成長；我建議 Side Project 的內容最好是自己非常感興趣的，因為自己感興趣才有在下班後一直做下去的毅力。

  • 靈感來源
    • 現實生活中的需求
      筆者有一個擔任社群小編的朋友，因為他每天都需要花大量的時間，蒐集與公司同類型品牌的粉專資料來做數據分析，所以他便詢問我是否能將蒐集資料的步驟自動化；因此我就寫了一個爬蟲專案來滿足他的需求，詳細的資訊大家可以參考我上一屆鐵人賽的內容。
    • 自己的興趣
      因為本身非常喜歡魔術，所以在生日收到朋友送的 Micro:Bit 開發板時，我就把它改造成一個可以玩心靈魔術的骰子；有興趣的讀者可以參考筆者的Github，裡面有完整的製作流程。

如果可以，我希望大家在做 Side Project 時不只是為了讓履歷更好看，而是真的有想要完成某件事的熱情；這裡也特別提醒大家，千萬不要為了增加 Side Project 數量，就把其他人的作品 Clone 下來稍微修改就說這個是自己做的，夜路走多了總是會遇到鬼。

4.2 自媒體

你不說，別人怎麼知道你有多強？

經營自媒體真的沒有你想像的那麼難，我們平常使用的 FB、IG 都是自媒體的一種；通常我們在上面看到的都是朋友分享吃喝玩樂功成名就的動態，所以當你突然定期的發一些技術文章、影片，相信我，你在朋友圈會變得很有記憶點；甚至周圍的朋友會給你取「部落格男、技術宅」的綽號，但這又有什麼關係？下面讓我跟你分析這樣做的好處：

  • 會跟能夠教學是不一樣的層次，把專業轉化成文章、影片的步驟，是一個讓你再次深入理解、整理這些知識的機會。
  • 當你朋友有相關需求時會第一個想到你，讓你獲得更多額外的機會（ex：工作、外包、演講）。
  • 只要你堅持兩個月以上定期發文，你就會自然而然地養成這個習慣，你會逼自己去做這件事來符合社會期待。

我知道很多人不習慣在社交平台上發專業性的文章，但除非你是天選之人，不然只在特定平台（ex：Medium）發表文章往往很快就會滅火，因為你的競爭對手實在是太多了，你幾乎無法獲得反饋；一開始可能不在乎，但時間一長這種缺乏互動的狀況，會讓你喪失寫文的動力；所以，勇敢的在社交平台發文吧！（推坑）

4.3 特殊經歷

專業幫你獲得面試的入場卷，但經歷才是這份工作的敲門磚。

老實說只要能獲得面試機會，就代表你的技術符合公司需求；但這麼多性質類似的求職者，如果沒有個人特色，公司可能就挑最便宜的那個。

如果你不想跟其他求職者打價格戰，你就必須有一些普通人所沒有的經歷，這裡所說的經歷並不限制於技術方面，舉例：

  • 完成 42k 全馬
  • 熱愛極限運動
  • 帶領團隊參賽得獎
  • 有豐富的舞台表演經驗
  • 積極參加各種比賽（ex：iT 邦幫忙鐵人賽）

面試時技術題可以透過刷題、精密的準備取得好成績；但特殊經歷就不太可能是假的，它往往反射著一個人真實的人格特質，如果這個人格特質受到面試官的欣賞，就算他在技術方面不是最優秀也可能被破格錄取，這就是所謂雙方的氣場很合拍。

備註：就算參加比賽沒得獎也可以列上去；如果得獎是對勇士的嘉獎，那參賽就是身為勇士的證明。
