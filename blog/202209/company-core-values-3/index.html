越來越多科技公司強調自己的核心價值，但你認同嗎？（三）

在前兩篇文章中（連結 1、連結 2），我們討論了為什麼企業需要核心價值，以及核心價值淪為口號的原因。

失敗的案例給我們警惕，成功的案例讓我們思考。好的策略固然重要，但執行策略的是「人」，如果核心價值與企業文化能被員工認同，那執行起來肯定更加順利，甚至超乎想像。

筆者這幾年剛好見證身旁的友人以「科技 X 展覽」作為突破口，成功讓企業在競爭激烈的科技產業中獲得一席之地；他們能成功除了剛好趕上越來越多展覽有數位化的需求，另一個很重要點的就是「員工對公司的向心力很強」。

就讓我們透過這篇文章，來看看他們做了哪些事。

老闆與主管以身作則

核心價值是否能實踐，很大一部分取決於老闆與主管的實際作為。

如果連公司高層都無法以身作則，那團隊成員當然有樣學樣；相反的，如果高層都以最高標準在要求自己，那團隊成員長期耳濡目染，會自然而然養成一樣的「習慣」，隨著時間積累，「文化」就慢慢塑造起來了。

身教重於言教。

題外話

這個老闆原本是技術出身，但在團隊擴張的過程中，他積極學習管理技能；因為公司涉及的業務涵蓋藝術領域，所以他也花費許多心力掌握相關知識（現在已經達到業界講師的水準）。

他認為一個合格的領導者，就算無法在每個領域都成為專家，也至少要具備與專家溝通的基礎知識；如果只聽從專業人士的分析而自己一無所知，那很容易做出錯誤的決策。

核心價值是從已經存在的優點提煉出來的

有些企業提出的核心價值是「未來改變的方向」，而這間企業的核心價值則是「要持續保持的優點」。

他們的核心價值並非憑空想像，而是從過去團隊的成長史分析得來的；可以說企業的品牌故事就已經涵蓋核心價值，而在這些核心價值被提出來前，其實大部分員工就已經遵從並視其為文化。

因為早已習慣，所以根本沒有所謂需要抽考、背誦、適應的問題。

新進員工往往很快就融入環境，正所謂：「蓬生麻中，不扶而直。」（當然無法接受的人也很快就離職）

讓正循環持續

許多企業把「創新」當成核心價值，但如果高層腦袋裝的還是過時的知識，那再好的想法也很難實現。

這個老闆為了避免管理階層思維老化、基層停止學習，他每個月都會舉辦一場分享會，除了邀請有豐富實務經驗的講師前來授課外，還會讓基層、管理階層輪流上台分享、交流，而他自己也會排除萬難的參與會議。

為了避免分享會造成員工負擔，除了舉辦的時間定在上班時間外（通常是星期五下午），上台報告的人也可以於上班時間做準備，盡可能不要讓員工因為這個分享會，導致必須加班才能完成現有工作。

定期審視可以調整的地方，並與獎懲機制掛鈎

核心價值勢必會隨著企業發展、市場輪動而調整，如果沒有定期審視，就有可能做出錯誤的決策。

以這個企業舉例，他們在初期為了搶佔市場，核心價值是「效率」導向；但在市場格局穩定後，核心價值就改為「品質」導向。

為了讓成員願意跟隨企業的核心價值，除了在例行性會議上宣傳外，也設計了與之對應的獎懲機制，讓成員了解努力的方向，以及預計會獲得的報酬。

雖然這樣說很殘忍，但過去陪老闆開疆拓土的員工，可能隨著企業核心價值的調整，從適合變成不適合。

筆者的觀點

不同規模的企業，在不同時期都有適合自己的核心價值。

以筆者所舉的這個案例來說，企業的核心價值之所以能從上而下，有很大一部份源自於老闆的個人魅力。

這個老闆現在三十多歲，還有體力學習、奮鬥、緊跟時代的步伐；但如果把時間拉長，在十年後他可能就無法用現在的模式來經營企業了

在這個系列文中，筆者從不同的視角來和大家一起探討企業的核心價值與文化；但學識與經驗不足，謬誤難免，尚祈讀者不吝指正與提供補充。
