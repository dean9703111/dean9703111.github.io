PM 的最佳輔助！跟 ChatGPT 聊天就能產出 PRD（產品需求規格書）

林鼎淵
2023.01.26 閱讀約 3 分鐘

  3. SETP 3：讓 ChatGPT 做更詳盡的規劃
  4. SETP 4：請 ChatGPT 產出 PRD
  5. Other：一些額外的 Bonus

無論你是不知道 PRD 怎麼寫，還是 PRD 寫到厭世，ChatGPT 都能緩解你工作上的壓力！

筆者過去兼任 PM 時，最困擾的問題是「不知道有哪些需求」以及「不知道需求怎麼開」，常常上頭丟一個主題給你後，剩下的要自己想辦法補全。

但問題是有些主題自己根本沒有接觸過，需要參考市面上的其他系統才有辦法撰寫規格；因為不熟悉，所以開出的規格常常漏東漏西。

不過在試用 ChatGPT 後，過去困擾我的問題就這樣迎刃而解（因為他最擅長發想＆補細節）；這篇文章筆者將跟你分享我如何「聊」出一份 PRD。

大綱

SETP 1：說明自己要做的事，並初步詢問建議
SETP 2：簡述需求，請 ChatGPT 補充細節
SETP 3：讓 ChatGPT 做更詳盡的規劃
SETP 4：請 ChatGPT 產出 PRD 
Other：一些額外的 Bonus

假使今天公司為了更有效率地進行面試，需要開發一套線上測驗系統，供考生進行中文、英文、邏輯的測試。

SETP 1：說明自己要做的事，並初步詢問建議

我要幫公司做一個線上測驗系統，給來公司面試的人做測試。

預計會有中文、英文、邏輯等 3 個考試項目。

在系統的規劃上，我有什麼需要注意的嗎？

SETP 2：簡述需求，請 ChatGPT 補充細節

我預計系統會分成兩塊，一個是給考生使用，另一個是給管理者使用。

管理者可以新增考生、管理試卷、查看分數。

上述需求可以幫我列出要考慮的細節嗎？

SETP 3：讓 ChatGPT 做更詳盡的規劃

我們可以要求 ChatGPT 針對自己給出的細節，做出更詳盡的規劃，比如：

  • 關於考生登入的系統，可以幫我規劃他的操作步驟嗎？
  • 關於管理者的系統，可以幫我把它可能會用的功能細分整理嗎？

SETP 4：請 ChatGPT 產出 PRD

如果你覺得細節都聊得差不多了，就可以讓 ChatGPT 產生 PRD 嚕。

可以幫忙把剛剛聊的內容整理成一份「產品需求規格書」嗎？細節越詳細越好。

接著你就會得到一份 PRD 的草稿如下：

Markdown 版本：Github

這份 PRD 草稿，大概是筆者跟 ChatGPT 對話 5 分鐘後得到的成果；也許不盡完美，但已經把系統的輪廓描繪出來了。

使用者可以根據這份 PRD，再去調整細節與補充邏輯。

Other：一些額外的 Bonus

下面是筆者自己操作下來的心得，大家可以參考一下：

  • 只產出部分 PRD：在產出 PRD 後，如果你覺得有不夠清楚的部分，可以再跟 ChatGPT 說明，請他針對「這個部分」產出就好。
  • 分次提供需求：今天筆者是以一個微型系統來做示範，如果要規劃一個大型系統，我會建議你分次提供需求（拆分子功能來規劃）。
  • 可以直接產生 DB Schema、SQL：你可以要求 ChatGPT 以剛剛的需求規格，來規劃資料庫、撰寫 SQL。

關於用 ChatGPT 聊出 PRD 的操作就分享到這裡，希望對大家的工作有所幫助～
