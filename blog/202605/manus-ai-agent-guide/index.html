這幾年協助企業導入 AI 時，發現對大部分的企業來說；他們判斷是否要導入一個 AI 工具的標準，除了功能與實際業務的「匹配度」外，他們其實更在意工具的「使用門檻」。

因為只要使用門檻高，不管工具有多強大，通常上完課後只有少數人會繼續使用。

我過去也分享過很多 AI Agent 的工具，但大多需要打開程式碼編輯器，甚至搭配終端機操作。

這對沒有技術背景的人來說，容易產生抗拒感，甚至使用初期會有挫折感。

所以今天要跟大家分享一款普通人可以快速上手的 AI Agent 工具，他就是「Manus」。

並搭配實戰案例，讓你了解這款工具可以給你的生活、工作帶來哪些幫助。

完整的 Demo，可以觀看 YT 喔 👉

對 AI 應用感興趣的朋友，歡迎按下訂閱按鈕，未來我計畫分享一系列 AI 工具的應用教學。

【Manus 實戰教學】從研究、簡報到個人網站，帶你掌握普通人也能上手的 AI Agent

從對話型 AI 到任務型 AI

過去我們使用網頁版的 Chatbot，通常比較像是在跟 AI 對話，就算討論得到了結果，最後還是要自己動手去做；而 Manus 不一樣的地方在於，你可以真的把任務交給它。

  • 基本任務、進階任務：它除了可以幫你做到基本的搜尋資料、整理資訊外，生成簡報、建立網站這些進階工作也能搞定。
  • 工具連結：如果給他權限連結到 Gmail、Google Calendar、Notion 這類工具，它還可以成為一個更全能的助手。
  • 重複任務：假使你有一些重複性任務，也可以打包成 Skill 技能；這樣你只要教會 AI 一次，之後遇到類似任務時，AI 就知道如何應對。

把事情做完，不等於把事情做好

在進入實戰前，先跟大家分享一個很重要的觀念。

讓 AI 把事情做完，跟讓 AI 把事情做好，其實是兩件事。

因為以現在 AI 的能力來說，如果只是想應付交差，一行指令就夠了。

不管企劃、簡報、音樂、影片，甚至連網站、手機 App 都可以一鍵生成。

但做得出來，不代表做得好，如果希望結果符合需求，你要先搞清楚自己要什麼。

所以我除了分享 Manus 有哪些功能外，還會分享自己與 AI 對話的技巧，並搭配實際案例，讓大家了解 AI Agent 可以如何融入我們的工作與日常中。

從釐清需求、生成研究簡報，到建立個人品牌網站都有具體操作，會由淺入深的帶大家掌握工具。

① 根據個人背景，掌握技術重點

註冊 Manus

這些積分，能讓我們使用 Manus 各式各樣的 AI 功能；給大家一個初步的概念，像我生成一個 15 頁圖文並茂的簡報大約需要 300 積分。

為了讓大家更清楚 Manus 的能力，這篇文章我是用付費版示範給大家看的（順手幫我點個讚吧）。

不要盲目使用工具

這裡先分享我是如何快速掌握一款新的 AI 工具，畢竟現在市場上的工具太多了，而且每天都在更新。

如果每接觸一款新工具，都自己人肉測試，那其實很容易錯過好工具；因為憑感覺使用一款工具，未必會試到這個工具對自己有幫助的地方。

所以現在接觸新工具時，我都會先請 AI 幫忙研究。

畢竟人的時間有限，我們也不需要精通一個 AI 工具的所有功能。

最重要的，是知道：「這個工具有哪些功能，是真的對我有幫助的。」

使用 Chat 模式節省積分

我先分享一個節省點數的技巧，其實 Manus 有分成 Chat 模式跟 Agent 模式。

一開始與 AI 討論問題、腦力激盪的時候，我們可以先用 Chat 模式。只要點擊右下角的更多，就可以看到「Chat 模式」。

請 AI 規劃學習指引

比如我想知道 Manus 可以給我帶來哪些幫助，就可以貼上提示詞跟他詢問

我是一名工程師、協助企業導入 AI 的內訓講師，同時也經營 YouTube 頻道。

我想要了解 Manus 有哪些功能可以幫助我更快完成工作。

請你從官方網站、網路文章與近期社群媒體的討論中，幫我整理 Manus 目前最值得關注的功能、實用技巧與應用場景。

每個場景附上對應的提示詞，讓我體驗 Manus 的強大。
  • 背景描述：一開始我先說明自己的背景資訊，是工程師、企業內訓講師，也是 YouTuber。
  • 研究方向：這邊就請他從公開資訊，整理 Manus 有哪些功能可以幫助我更快完成工作。
  • 行動指引：最後為了方便驗證功能，我要求他要附上提示詞，這樣可以方便我們後續的行動。

送出之後 Manus 很快的就給了我們行動指引，下面這份報告是根據我的提供的背景來介紹 Manus 的，並根據不同身份，給予對應的應用場景，並在下方提供可以直接實戰的提示詞

執行完畢後，我們點擊右上角文件的符號，可以看到在 Chat 模式下使用積分為 0。

也給大家看一下 Agent 模式有什麼不同，這裡我就點擊「啟動 agent」。

你會看到 Manus 啟動一台虛擬機，然後自己打開瀏覽器、搜尋資料、看網頁、整理內容，感覺就像一個真的助理在幫我們做事一樣。

稍等一段時間，他就幫我們生成了一份報告，跟 Chat 模式相比，因為多了搜尋資料整合案例的步驟，研究成果會更有深度且符合實際需求。

所以在每個應用的技術上也會說得更加完整，我們了解工具中哪些功能對自己有幫助後，再做針對性的測試，可以幫我們節省不少盲目使用時間。

② 從釐清需求到生成簡報

我其中一個身份是企業講師，常常要到不同產業授課，為了讓學員有共鳴，我需要根據公司情境把案例客製化。

但坦白說，許多產業對我來說也是完全陌生的領域，所以備課時，都是請 AI 幫我研究主題、設計案例。

其實別說是我，大家日常工作也是一樣的。

可能主管突然丟一個主題，要你做市場調查、整理資料；然後要求你今天下午或明天，就要上台跟同事做簡報分享。

哇～光是想像這個場景，我整個壓力就上來了！

如果你跟我有一樣的痛點，那千萬不要錯過接下來用 AI 生成簡報的案例。

不要一開始就叫 AI 做簡報

這邊我們一樣先使用 Chat 模式。

STEP 1: 優化提示詞

提醒一下大家，如果你打算請 AI 做簡報，那第千萬不要一開始就讓 AI 做簡報；而是先初步提出自己的需求，並讓 AI 優化提示詞。

這個步驟會讓 AI 補充許多你一開始沒有考慮到的細節

我是一間台灣汽車零件零售業的廠商。

我們銷售的汽車零件包含：「煞車系統零件、濾芯、底盤零件、引擎周邊零件、常見保養耗材。」

目前在評估是否進軍東南亞，希望切入 Tier 2 或售後維修市場

我需要製作一份簡報給主管，說明建議的切入策略

請你幫我把上面這段需求，優化成更完整、更適合交給 AI 研究的 Prompt，用 Markdown 顯示
  • 背景描述：一開始我先說明自己的背景是「汽車零件零售業的廠商」，並提供主要的販售項目。
  • 初步目標：進軍東南亞，切入 Tier 2 或售後維修市場。
  • 受眾：主管。

一開始的需求描述模糊沒有關係，因為最重要的是最後一行：

請你幫我把上面這段需求，優化成更完整、更適合交給 AI 研究的 Prompt，用 Markdown 顯示

多了這行，AI 就會把原本初始的 Prompt 做更完善的優化。

同時也跟大家補充一下，這邊我之所以要求使用 Markdown 格式，是因為它輸出的是結構化，有明顯階層的。

像這邊你就看到，原本只有四行的提示詞，在 AI 的幫助下補充了這麼多細節，大標、次標、描述的層次都很清楚。

STEP 2: 請 AI 反問我還缺什麼

乍看之下，上面的 Prompt 感覺已經很完善了對吧？但這個時候我會建議大家換個角度。

讓 AI 反問自己，如果補充哪些背景資訊可以得到更完善的結果。

從市場研究顧問的角度來看這段 Prompt，如果要完成這個研究，我還需要補充哪些資訊，才能讓你產出更精準、更符合商業決策需求的結果？
每個問題請簡短說明：

1. 為什麼需要這個資訊
2. 如果缺少這個資訊，可能會影響哪一部分的分析

這步非常重要，因為很多時候我們根本不知道要提供哪些資訊，與其自己硬想，不如讓 AI 幫我們檢查，這也是我覺得跟 AI 協作很重要的一個概念：

不是只有你問 AI 問題，你也可以讓 AI 反問自己

在收到問題後，大家可以自行補上必要資訊；這邊我為了示範，所以讓 AI 自問自答一下

用公司老闆的身份，模擬回答上面問題。

STEP 3: 先設計簡報大綱

在背景資訊完整後，接下來也不要直接製作簡報，先幫我設計一份約 15 頁的簡報大綱

幫我設計一份約 15 頁的簡報大綱。內容涵蓋：

1. 簡報主軸
2. 每一頁的標題
3. 每一頁要說明的重點
4. 建議搭配的圖表或資料類型

用 Markdown 顯示

之所以要先做大綱，是因為如果直接請它生成完整的簡報；除了會花比較多時間外，每次生成簡報也會消耗不少積分，如果方向錯了，後面要改的地方也會很多。

因此我建議先讓 AI 產出大綱，確認方向符合預期後，再生成完整的簡報，這樣可以減少很多來回修正的時間。

STEP 4: 生成圖文並茂簡報

在大綱生成出來，確認符合需求後就可以生成投影片了，最簡單的方式是點擊建立，選擇「投影片」。

這這種方案我們對生成結果的掌控力是很低的。

所以我建議大家先把簡報大綱複製起來，儘管這次 AI 是用表格生成，但點擊右下角也是可以把內容複製起來的。

開一個新對話窗，點擊「製作簡報」，這邊你換看到三種選項，分別是專業、GPT 與 Nano Banana。

  • 專業：如果你想要製作的以 HTML 為主，重點呈現文字跟圖表，方便大家直接編輯細節，風格偏向傳統簡報。
  • 圖片視覺：而如果你希望每張投影片的視覺效果拉滿，就選擇 GPT 或 Nano Banana。

如果選擇專業的話，也有許多模板可以選擇：

稍等一段時間，簡報就製作完成了，你會發現透過以上步驟製作出來的簡報，內容詳盡、結構完整、而且有適當的搭配圖表。結果會更符合你一開始設定的目標。

但提醒一下大家，AI 生成出來的結果有可能會錯誤，若涉及數據、真實資訊，請自行核實

用專業模式生成的簡報，裡面的文字也是可以編輯的。

如果你想要調整成其他風格的簡報，可以點擊右下角的「更改主題」，從裡面選擇自己喜歡的版型。

如果不知道上台怎麼講，點擊右下角的「讓 Manus 生成」，他就會根據每一頁簡報的內容，設計出有起承轉合的逐字稿，讓你上台分享時更有底氣。

當然，你也可以把它下載成 PPT 來精修細節、或用 PDF 格式與別人分享，甚至想在 Google Slide 編輯也可以喔！使用上非常有彈性

③ 把繁瑣的任務，整理成可以重複使用的 Skill

這邊分享一個實用的技巧，剛剛我們不是透過好幾輪對話才得到這個結果嗎？

如果每次研究新主題都要這樣搞，感覺太煩了吧；幸好 Manus 有提供建立 Skill 的方案。

可以透過「/skill-creator 描述」幫剛剛繁瑣的流程，建立為可以重複使用的技能喔！

/skill-creator 幫我把剛剛提供主題生成簡報的流程設計為 Skill，日後提供主題就會觸發

最後會記錄成一個文件，打開後點擊「新增到我的技能」，AI 日後遇到類似的任務時，就會按照指引來去執行。

如果想找尋儲存好的技能，可以點擊左下角的個性化，在功能列就會看到技能。

剛剛建立好的技能會存放在這個位置，技能除了可以自己建立外，也可以匯入別人建立好的技能喔！

驗證 Skill 是否符合預期

在 Skill 建立後，建議大家可以提供另外一個主題，來驗證這個 Skill 是否會順利觸發，以及觸發後，是否有順利運作。

這邊我就給他一個新主題，讓他研究亞洲餐飲行業近十年的的趨勢：

請研究亞洲餐飲行業近十年的的趨勢，品牌爆紅的關鍵，以及是否維持的關鍵因素，請幫我製作一份 12 頁的高端專業研究簡報。

指令送出後，可以看到 AI 有使用剛剛建立的 Skill。

稍等一段時間，我們就能看到 Manus 根據我們剛剛的需求建立簡報。

只是這次他認為我提供的主題更偏向說故事，所以採用 Nano Banana（圖片視覺）的方式來建立簡報。

跟前面專業模式透過 HTML 生成簡報的方式相比，你可以明顯感受到簡報的圖片品質非常棒。

但因為個簡報其實是圖片，儘管你也可以編輯裡面的文字；但這些細節的調整就等於重新生成一張圖片，修改起來比較花時間。

所以在使用上，如果簡報的重點是傳達故事、概念，我覺得視覺化簡報的方案很棒。

但假使簡報需要時常調整數據細節，涵蓋大量圖表，我會推薦使用專業模式來生成 HTML 簡報。

④ 整理不同格式檔案，建立個人品牌網站

接下來我們換個場景，如果你是自由工作者或一間新創公司，那最重要的就是讓別人認識你、找到你。

相比於傳統名片，我認為建立個人形象網站或公司官網，會達到更好的宣傳效果。

在過去，如果你不會寫程式，可能要把網站交給外包公司；但現在，你可以請 AI 幫你完成網站的初稿。

請 AI 整理資訊

這邊我就拿自己當案例示範給大家看；這次我的目標是建立個人形象網站，所以下面要先選擇「建立網站」，然後選擇「個人連結頁」

我是個講師，準備製作個人形象網站，相關背景資訊可以參考附件的檔案

幫我從裡面提取出文字後，整理出如下資訊：

- 擅長領域: 搭配可以佐證的資訊
- 個人成就: 找出可數據化的成就，展現實力的強大
- 課程資訊: 課程主題、說明、價格、受眾、預期成果

並像個善於推銷自己的 KOL 般，先用自信的語氣撰寫出文案，並說明每段適合搭配的圖片

這步先彙整資訊，不需生成圖片與網站

這段 Prompt 我先表明自己的身份是「講師」，要求他根據我提供的素材，整理出「擅長領域、個人成就、課程資訊」的資訊，以此做為「個人形象網站」的素材

如果你的目標是建立公司官網，請 AI 幫你生成對應提示詞就可以了

這段想要呈現的，是 Manus 針對不同格式檔案的資訊分析、彙整能力

你可以看到我上傳的有 Word、PPT 跟 PDF 檔案，這也更符合實際工作場景，因為資料來源往往是不統一的。

生成網站

在彙整完資訊後，你可以先看看 AI 整理的資訊是否符合期待。

確認沒問題後，就可以上傳網頁所需的圖片，然後透過下面的指令來生成網站了

請使用我上傳的圖片，參考圖片檔名放到網頁合適的位置，讓整體更有設計感與專業度

設計純前端的個人形象網頁即可

在 Manus 生成網站的過程也提醒一下大家，因為我跟他說生成存前端網站，所以有較高機率給我一個單純的 HTML 檔案。

如果你生成的是較為複雜的專案，甚至包含到後端與資料庫，操作的細節會跟這次示範有所不同。

稍等一段時間，Manus 就根據我們提供的文件與圖片幫我們完成了一個測試網站，我們先點擊一下網址，看一下他是如何設計的。

Manus 連接器

確認整體符合需求後，這邊剛好跟大家介紹 Manus 連接器的功能。只要開啟對應工具的權限，Manus 就可以透過 API 來進行操作。

因為我已經有連結到 GitHub 帳號，所以他可以直接幫我建立對應的 Repository。

這邊提醒一下大家，雖然權限開越大 AI 能做的事越多；但前提是你了解自己在做什麼，否則可能造成無法挽回的後果。

了解完風險後，我們回到 Manus，下面我就直接跟他說：

我已經連結到 GitHub 帳號，幫我建立

等待一段時間後，發現 AI 暫停了。這邊他要我們接管瀏覽器，完成 GitHub 帳號的登入，或提供帳號密碼來讓 AI 代為操作。

但只要在瀏覽器登入帳號，基本上就等於讓 Manus 擁有帳號的完整權限，我個人是不敢這樣做。

面對有風險，但我們又不清楚如何操作的事情，也可以向 AI 詢問操作步驟：

告訴我後續的操作步驟

在 GitHub Actions 確認部署狀況

這邊補充一個細節，關於部署的狀態，我們是可以在 GitHub Actions 的分頁來觀察的。

另外把專案存放到 GitHub 後，其實也順便做到了版本控制。

因為與 Manus 對話，調整網頁時，可能會改到許多程式，未必每次都符合你的期待。

但有了 GitHub，在結果不如預期時，便可以輕鬆回到過去的版本。

接著回到 Manus 網頁，在部署完成後，點擊連結便可看到剛剛建立的個人形象網頁；你可以把網址分享給自己的朋友，展示自己的戰果喔！

範例網站：https://deanlin.net/dean-lin-website/

如果做到了這一步，也別忘記幫文章點個讚，讓我知道自己的分享是對大家有幫助的。

透過對話優化網站細節

另外如果你對網頁有其他優化的需求，也可以直接跟 Manus 說，這邊就分享一個小技巧。

如果你想要讓網站圖片渲染的速度更快，可以把圖片轉成 webp 格式。

幫我將圖片轉成 webp 格式，讓使用者可以更快載入網頁

指令送出後，AI 除了會幫我們把圖片檔進行壓縮外，因為我們有開啟 GitHub 的權限給 Manus，所以他也把變更同步到了 GitHub，我們可以點擊網址來做確認。

恭喜你，成功用 Manus 完成了個人形象網站！
