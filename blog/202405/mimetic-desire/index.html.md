# 慾望來自於「模仿」，你被慾望控制了嗎？

- 摘要：升職加薪、財富自由、買奢侈品、跑馬拉松、攀登百岳… 你想過嗎？絕大多數我們所追求的慾望，都是模仿他人而來的。

升職加薪、財富自由、買奢侈品、跑馬拉松、攀登百岳…

你想過嗎？絕大多數我們所追求的慾望，都是模仿他人而來的。

而慾望近乎永無止盡，就像某款能量飲料的廣告詞：「你永遠無法滿足。一旦得到，就會渴望更多。」

相比於過去任何一個時代，生活在社群時代的我們，更容易陷入慾望的深淵。

## 當身旁的人成為你模仿對象

在網路不普及的年代，我們的榜樣往往是偉人、名星、成功人士。

因為這群人高不可攀，所以就算我們沒有取得他們的成就、財富，依然能開心的過自己的小日子。

但現在社群媒體發達，大部分的人在社群也往往只展現出自己最光鮮亮麗的一面。

因此我們的模仿對象也許會變成身旁的朋友，當你看到朋友買了名車豪宅，出入各種高階場所時，可能心中會冒出一個想法：「我也想跟他一樣！」

**但物質的攀比，通常只會讓自己活得更痛苦。**

## 好朋友都希望對方過得比別人好，但是不能過得比我好

如果看到新聞上有人中樂透，你頂多就是羨慕。

但如果身旁朋友突然靠投資虛擬貨幣財富自由，你可能瞬間就覺得不幸福了。

而這種不幸福的感受，很有可能導致你做出錯誤的判斷。

就像有些人看到別人靠投資一夜暴富，就會誤以為自己也能辦得到，但最後的結果往往是敗光多年積蓄。

## 離開惡性循環

如果你社群媒體的版面充滿炫富、購買奢侈品的資訊，而你的消費能力又無法與之匹配時，那這些萌芽的慾望往往會讓你更痛苦。

假使下面再搭配一些投資理財的廣告，你可能一個衝動就被詐騙了。

環境對一個人的影響非常深遠，如果你發現自己不適合這個圈子，那應該主動離開。

## 重新建立良性循環

跟風炒作、追逐虛榮往往只能獲得一時的快感。

而選擇合適的圈子，把目標放在可長期經營的事情上（ex：專業技能、興趣愛好），也許你會覺得自己的人生更有意義。

既然模仿是人的天性，那我們就能透過改變環境來控制慾望的方向。
