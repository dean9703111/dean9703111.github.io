先談談 5G 能給我們的生活大來哪些改變

AR 產業：讓擴增實境中的影像能達到 4k 的水平

從下面琴酒(BOMBAY)的廣告當中我們能看到他透過 AR 的技術讓客戶對產品有更好的體驗，並可直接取得相關的調酒、飲用等相關知識。

但是以往 AR 產業面臨的難題是每個客戶的網路水平不一導致實際的體驗不好，時常遇到：『畫面卡住、畫質差、雜訊多、定位不精準』等問題，而這些問題能在 5G 的網路下得到很多的優化。

這是一個主題圍繞在 5G 、Google map、AIOT 的分享，內容著重在分析 5G 在不同產業的實質應用、5G 與 wifi-6 的比較、Google map 的相關應用

Augmented Reality for Packaging - Shazam x Bombay Sapphire

家用 wifi 會逐漸被市場淘汰

我想已經有非常多人已經把家中的 wifi 給淘汰了，因為回到家後用手機的 4G 熱點其實已經滿足了我們的使用需求，現在家中還繼續使用 wifi 的可能是因為 4G 的訊號不穩定、網路忽快忽慢、訊號穿透力問題等等導致需要穩定網速時只能使用 wifi。

但是據講者所說，5G 的時代來臨後幾乎沒有家用 wifi 的生存空間，因為相比於 4G，5G 擁有強大的訊號穿透力、穩定性，彌補了過去 4G 時代的遺憾。

部分工廠會考慮使用 5G 作為內網

過去工廠都是使用 wifi 作為內部網路使用，主要是因為 4G 網路在工廠的環境極度不穩定，但是現在 5G 的穩定度提升上來了，甚至可以專門為一個工廠佈建 5G 私網。

從上面的論點看起來 5G 似乎要稱霸天下取代 wifi 了；但是因為 5G 的佈建成本比現在的 wifi-6 高很多，所以目前看來 5G 要完全取代 wifi 還有一段路要走。

醫療產業的應用

在病人被送上救護車時如果沒有給予正確的救治可能導致二次傷害，5G 的穩定性及速度可以讓醫生在醫院透過影像給予現場救護人員正確的指示讓他們及時施救。同樣的 5G 的技術也讓遠端開刀不再只是空想。

急難救援(AIOT)

現在的救災不再依靠紙筆紀錄及電話溝通，而最高領導者也不需要抵達第一現場才能給予指示。

自從有了無人機後，我們便可依靠它大力幫助現場救援；我們可以透過無人機的空拍畫面了解現場災害狀況，並透過相關影像辨識技術及時給予救災建議，除此之外無人機在發生火災時的灑水救援也能作為消防隊員抵達前的緊急應變並減緩災難擴散、遇到有人溺水時丟救生圈也會更加及時且保障救難人員的生命安全。

貨運行業

我想很多人都有一個通點，就是貨送到你家的時候你人不在，此時又沒人能協助你收貨，所以 Amazon 就設計了一款能夠遠端打開自己家門讓送貨員放東西的產品，而送貨員進到家門前以及放下貨品的每個動作都有即時影像的紀錄讓你更能掌握現場狀況。而 WAL-MART 也推出可以讓送貨員將生鮮食品放到你冰箱的服務。

Google map 成功應用的案例

救護車行駛路線

很多的事故是在救護車執勤時所發生的，常常因救人時影響到整體交通的安全衍生了許多事故。

而如果我們能及時分析出行駛的路線並讓整條道路都綠燈通行，不但能大大減少可能發生的事故並且能讓救護路程更加順暢

房仲產業

現在的房仲不只是在地圖上標記建物，更能直接推薦附近的仲介為您服務，通時也讓你能透過地圖直觀的了解建物周圍的生活機能，這樣能節省大量塞選房源的時間。

地圖遊戲

過去最火紅的寶可夢也是依據 Google map 來做相關開發演進的，讓你對地圖的未來可能性有更多的遐想。

提供最愉快的消費體驗

現在你從網路上搜尋你想要購買的產品，搜尋引擎不光會顯示不同網路商店的價格，更會顯示這些實體店家距離你多遠，也許在不久的將來他們甚至會包括：『最快可完成結帳的店家、距離最近的店家、價格最低的店家、店家附近有哪些停車場(還剩下多少停車位)』這些資訊。

販賣機應用

現在的販賣機販賣的東西已經遠遠不止於罐裝飲料了，現在販賣機中麵包、生鮮食品、便當都可以選購，但這些產品跟罐裝飲料比起來保鮮期間短，缺貨速度快；所以產品物流就顯得格外重要，舉凡哪些機台需要補貨、怎樣的補貨路線最適當都是要考慮的問題。

而這些販賣機都有綁定會員，並記錄每個會員過往的消費記錄，所以也更能人性化的推出個人專屬優惠增加成交率。

會議中印象深刻的話題

AI 取代過去需要大量勞力及經驗的工作

在會中有提到一間傳統的紡織公司，他們在接觸 AI 技術之前如果要辨識一塊布料的組成需要老師傅的經驗以及大量的時間、想要開發一種新的布料也需要近一年的時間，但隨著導入機器學習，這些需要經驗與傳承的技術可以在幾秒鐘內被解決，說實話科技得演進真的讓人開心又沮喪。

好點子需要一個潑冷水的人

很多人常常腦中冒出一堆有趣的點子，跟身旁的朋友討論過覺得可行就開始實做了，但是這股激情絕大多數都會被現實潑冷水；如果一個產品沒有足夠完整的規劃絕大多數都會失敗(商業、成本、人事、行銷…)

當然也沒有一個一上線就是完美的產品，就像是今年很火紅的口罩地圖，上面會顯示各個超商或是藥局的口罩庫存量，但實際上各個藥局可能是用發號碼牌的方式來領取，又或者數據更新的不夠即時導致前來購買的人撲空，如果考慮得更仔細甚至連物流補貨的時間點都要列入參數。發現不足才有進步的空間，但是沒有踏出第一步的人什麼都不是。

突破思想框架的束縛

現在 Ubereats、foodpanda 這類外送平台非常火紅，可是國外的外送平台已經衍生到更多有趣的發想了。

機器人送餐：在疫情的影響下，也許用機器人送餐是更安全且便捷的一個方式。

向移動中的客戶送餐：在國外有送餐平台是直接將餐點送到堵車的路段上，讓陷入車陣的人可以吃晚餐。

感想

5G 技術

應用著重在需要高速、穩定性高的產業，當 5G 技術普遍之後相信整個娛樂圈的市場也會有相當大的革新，以遊戲來比喻就像是小朋友齊打交進化到魔獸世界一樣；也許在不久的未來三維的展示會變得很普遍(現在市面上三維展示的畫質簡直不堪入目)。

Google map

幾乎任何產業都與他有千絲萬縷的關係，而且它的功能也依舊在不斷擴增，Google 也透過提供 api 給大家介接賺取大量營收，而這些 api 提供的資料其實全世界人民持續幫他完善的。所以在未來可以去思考在大數據的加持下 Google map api 還能解決哪些產業的痛點、還能做哪些創新的應用。

針對會議的感想

除了中間有家公司不停說自己有多強、拿了多少證書、跟多少公司合作這類毫無營養的內容以外其他與會分享的內容都是有價值的，推銷並不是在說自己有多強，而是要分享曾經解決了哪些問題。

其中一位講者在最後也說道：『今天的會議是在各位心中埋下一個 5G 、 Google map 應用的種子，也許未來某一天你工作遇到瓶頸時，這些技術就是你解決問題的良藥。』

感謝大家的閱讀，如果文中的知識有給你幫助，拍手與轉貼這篇文章是對我最大的鼓勵，謝謝。
