對工程師來說，終端機（Terminal）是我們每天都要用到的工具。

也許你已經用習慣 Terminal、iTerm2，但在 AI 時代，我們有更好的選擇。

Warp AI 將顛覆你使用終端機（Terminal）體驗，過去我們忘記指令（Command）可能要去 Google，但現在有了 Warp AI，這些問題在 Terminal 就能搞定。

不管是 git、docker 指令，還是想要寫一小段 Shell Script，Warp AI 都能助你一臂之力。

下載 Warp

可以透過我的邀請碼下載: https://app.warp.dev/referral/DDQGLQ

目前 Warp 可以在 Mac、Linux 等平台使用（文章發表時 Windows 尚未開放）。

使用時請遵守公司的資安規定，畢竟這款工具是在 Terminal 運行。

安裝的部分我就不再贅述，下面透過幾個常見的範例，Demo 給大家看他的強大之處。

不過要特別提醒一下，目前僅能使用「英文」來做對話。

Warp 基礎操作

打開 Warp 後，他跟你平常在使用的 Terminal 外型差不多。

不過如果輸入「#」就會轉換成 AI 對話模式。

Exmaple 1：忘記 Git 的指令怎麼用

Git 最常使用的就是 pull/push/merge/fetch… 這些指令。

但如果突然需要使用 rebase 來做版控，你可能就會熊熊忘記這指令怎麼寫，此時在 Warp 直接輸入：

# git rebase to a specific step

就會得到 AI 建議嚕！

Exmaple 2：用模糊名稱找出 Docker images

如果我們想用模糊名稱篩選出 Docker images。

# filter docker images by blurred name

Exmaple 3：撰寫 Shell Script

或是請他寫一段 Shell Script，讓我們批量修改某個資料夾底下的檔案名稱。

# write a shell script find specific folder and deep batch rename file under folder

使用限制

雖然 Warp AI Terminal 很好用，但他有免費額度使用量的限制，目前一個月只能使用 40 次。

如果升級到專業版，一個月為 15 元美金，額度提升到 500 次，更詳細的價格請看下圖。

使用心得

這款 AI 工具的體驗非常絲滑，對我這種不愛記指令（健忘）的工程師來說非常方便。

其他 Terminal 有的功能（ex: 記住用過的指令、快捷鍵）他也都有。

如果你感興趣，可以透過我的邀請碼下載: https://app.warp.dev/referral/DDQGLQ

更多的應用方式，也歡迎大家留言分享喔！

最後提醒一下，AI 生成的答案未必是正確的，你還是要保有自己的判斷能力！

另外也請遵守公司的資安規定來使用，畢竟這款工具是在 Terminal 運行 😀
