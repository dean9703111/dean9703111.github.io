## Warp 基礎操作

打開 Warp 後，他跟你平常在使用的 Terminal 外型差不多。

不過如果輸入「#」就會轉換成 AI 對話模式。

## Exmaple 1：忘記 Git 的指令怎麼用

Git 最常使用的就是 pull/push/merge/fetch… 這些指令。

但如果突然需要使用 rebase 來做版控，你可能就會熊熊忘記這指令怎麼寫，此時在 Warp 直接輸入：

```
# git rebase to a specific step

```

就會得到 AI 建議嚕！

## Exmaple 2：用模糊名稱找出 Docker images

如果我們想用模糊名稱篩選出 Docker images。

```
# filter docker images by blurred name

```

## Exmaple 3：撰寫 Shell Script

或是請他寫一段 Shell Script，讓我們批量修改某個資料夾底下的檔案名稱。

```
# write a shell script find specific folder and deep batch rename file under folder

```
