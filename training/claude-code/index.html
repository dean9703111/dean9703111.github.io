Claude Code 企業內訓Claude Code Workshop

Claude Code 是在終端機裡執行的 AI 開發工具。我的課會把它放進真實的開發流程：先把規格寫清楚，再讓 AI 在隔離環境裡動手，最後部署上線。

給工程團隊的版本談規格驅動開發與團隊的開發流程；給非工程師的版本，目標是讓 AI 交付一個自己用得到的成品。

04

常見問題

QClaude Code 的課需要先會寫程式嗎？

看版本。緯穎科技的實戰工作坊是給工程團隊的，談規格驅動開發與開發流程；數位實驗中學的場次，則是帶學員用 Claude Code 做出班級小工具。

Q課程內容和網站上的 Claude Code 文章一樣嗎？

方向一致，文章可以當作課前預習或課後複習：Claude Code 實戰系列從 OpenSpec、Docker 隔離環境寫到 Spec-Kit 與部署上線。內訓會依團隊的技術背景與想解決的問題調整範例。

Q團隊用的是 Cursor 或 Antigravity，也可以嗎？

可以。規格、測試與版本控制的觀念是共通的，我也開過 Cursor 與 Google Antigravity 的課，可以依團隊現有的工具調整。

QClaude Code 企業內訓怎麼邀約？

寄信到 babydragon9703111@gmail.com，說明單位名稱、學員對象與人數、預計時數和想解決的問題，我會依需求規劃課程內容；也可以按頁面上的「Email 洽詢」，信件會自動帶入邀約範本。
